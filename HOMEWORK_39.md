# Домашнее задание № 39: Модуль 21 - Разграничение доступа. Расширенные инструменты

## 📋 Описание задания

Реализовать полностью функциональную систему авторизации и аутентификации в Django проекте `todo_api`, включая:

1. ✅ **Вход (Login)** - аутентификация пользователя с поддержкой "Запомнить меня"
2. ✅ **Выход (Logout)** - безопасное завершение сеанса с подтверждением
3. ✅ **Восстановление пароля (Password Reset)** - полный цикл восстановления пароля по email
4. ✅ **Регистрация (Registration)** - создание новых пользовательских аккаунтов

## 🎯 Реализованные компоненты

### 1. Улучшенные формы (`tasks/forms.py`)

#### UserLoginForm
```python
- username: Обязательное поле
- password: Пароль
- remember_me: Чекбокс для запоминания (опционально)
- Bootstrap стили для красивого отображения
```

#### UserRegistrationForm
```python
- username: Уникальное имя пользователя
- email: Email адрес (уникальный)
- first_name: Имя (опционально)
- last_name: Фамилия (опционально)
- password: Пароль (мин. 8 символов)
- password_confirm: Подтверждение пароля
- Валидация совпадения паролей
```

#### CustomPasswordResetForm
```python
- email: Email адрес с проверкой существования
```

#### CustomSetPasswordForm
```python
- new_password1: Новый пароль (мин. 8 символов)
- new_password2: Подтверждение нового пароля
```

### 2. Представления (Views) - `tasks/views.py`

#### LoginView
- **GET**: Отображение формы входа
- **POST**: Обработка данных входа
- Поддержка "Запомнить меня" (延长сессию на 2 недели)
- Автоматическое добавление в группу "UserManagers"
- Валидация учетных данных

#### LogoutView
- Безопасное завершение сеанса
- Страница подтверждения выхода с приветствием

#### RegisterView
- **GET**: Форма регистрации
- **POST**: Создание нового пользователя
- Создание профиля пользователя
- Транзактивная обработка (atomiс) для целостности данных
- Валидация уникальности username и email

#### PasswordResetView
- **GET**: Форма запроса восстановления пароля
- **POST**: Отправка email с ссылкой для восстановления
- Генерация уникального токена
- Кодирование ID пользователя в base64

#### PasswordResetConfirmView
- **GET**: Страница установки нового пароля (при валидном токене)
- **POST**: Проверка токена и установка нового пароля
- Валидация срока действия токена
- Секретное хранилище ID в сессии

## 🚀 Использование системы

### Регистрация нового пользователя

1. Перейдите на `/register/`
2. Заполните форму:
   - Имя пользователя (уникальное)
   - Email (уникальный)
   - Имя и Фамилия (опционально)
   - Пароль (минимум 8 символов)
   - Подтверждение пароля
3. Нажмите "Зарегистрироваться"
4. Перейдите на вход

### Вход в систему

1. Перейдите на `/login/`
2. Введите имя пользователя и пароль
3. (Опционально) Отметьте "Запомнить меня" для более длительной сессии
4. Нажмите "Войти"

### Восстановление пароля

1. На странице входа нажмите "Забыли пароль?"
2. Введите email, связанный с аккаунтом
3. Проверьте почту (включая спам)
4. Нажмите на ссылку в письме
5. Установите новый пароль
6. Вернитесь к входу с новым паролем

### Выход из системы

1. Нажмите на иконку "🚪 Выйти" в навигации
2. Подтвердите выход
3. Вы будете перенаправлены на страницу подтверждения

## 🔒 Функции безопасности

### Реализованные механизмы защиты

1. **Валидация паролей**
   - Минимум 8 символов
   - Проверка совпадения при регистрации
   - Django PASSWORD_VALIDATORS

2. **Защита CSRF (Cross-Site Request Forgery)**
   - `{% csrf_token %}` во всех формах

3. **Токены восстановления пароля**
   - Уникальные токены для каждого пользователя
   - Срок действия 1 час
   - Невозможно использовать токен дважды

4. **Кодирование данных**
   - ID пользователя кодируется в base64
   - Токены генерируются с использованием Django security

5. **Сессии**
   - Безопасное хранилище данных в сессии
   - Timeout сессий
   - Поддержка "Запомнить меня" с правильным timeout

6. **Проверка уникальности**
   - Username уникален
   - Email уникален
   - Проверка перед созданием пользователя

### Производственные рекомендации

1. **Email конфигурация**
   ```python
   # Измените на production email backend
   EMAIL_BACKEND = 'django.core.mail.backends.smtp.EmailBackend'
   EMAIL_HOST = 'smtp.gmail.com'
   EMAIL_PORT = 587
   EMAIL_USE_TLS = True
   EMAIL_HOST_USER = os.getenv('EMAIL_HOST_USER')
   EMAIL_HOST_PASSWORD = os.getenv('EMAIL_HOST_PASSWORD')
   ```

2. **HTTPS**
   - Всегда используйте HTTPS в production
   - Установите `SESSION_COOKIE_SECURE = True`

3. **SECRET_KEY**
   - Никогда не коммитьте SECRET_KEY
   - Используйте переменные окружения
