# Практическая работа № 48

## Модуль 30. Разработка Web-служб REST. REST framework. Django REST Framework

### Задание

Придумать примеры 2-3 веб-приложений и описать их функционал.

## Пример 1. Онлайн-библиотека

Онлайн-библиотека позволяет пользователям искать книги, просматривать информацию об авторах и сохранять книги в избранное.

### Основной функционал

- регистрация и авторизация пользователей;
- просмотр списка книг;
- поиск книг по названию, автору или жанру;
- просмотр подробной информации о книге;
- добавление книги в избранное;
- создание отзывов и оценок к книгам;
- административное добавление, редактирование и удаление книг.

### Возможные REST API endpoints

- `GET /api/books/` - список книг;
- `GET /api/books/<id>/` - подробная информация о книге;
- `POST /api/books/` - добавление новой книги;
- `PUT /api/books/<id>/` - обновление информации о книге;
- `DELETE /api/books/<id>/` - удаление книги;
- `POST /api/books/<id>/reviews/` - добавление отзыва.

## Пример 2. Сервис доставки еды

Сервис доставки еды позволяет пользователям выбирать рестораны, оформлять заказы и отслеживать их статус.

### Основной функционал

- регистрация клиентов и сотрудников ресторанов;
- просмотр списка ресторанов;
- просмотр меню конкретного ресторана;
- добавление блюд в корзину;
- оформление заказа;
- изменение статуса заказа;
- просмотр истории заказов пользователя.

### Возможные REST API endpoints

- `GET /api/restaurants/` - список ресторанов;
- `GET /api/restaurants/<id>/menu/` - меню ресторана;
- `POST /api/cart/items/` - добавление блюда в корзину;
- `POST /api/orders/` - создание заказа;
- `GET /api/orders/<id>/` - информация о заказе;
- `PATCH /api/orders/<id>/status/` - изменение статуса заказа.

## Пример 3. Менеджер задач

Менеджер задач помогает пользователям создавать задачи, объединять их в проекты и контролировать выполнение.

### Основной функционал

- регистрация и вход пользователей;
- создание проектов;
- создание задач внутри проекта;
- назначение исполнителей;
- установка дедлайна;
- изменение статуса задачи;
- фильтрация задач по статусу, проекту или исполнителю.

### Возможные REST API endpoints

- `GET /api/projects/` - список проектов;
- `POST /api/projects/` - создание проекта;
- `GET /api/tasks/` - список задач;
- `POST /api/tasks/` - создание задачи;
- `PATCH /api/tasks/<id>/` - частичное обновление задачи;
- `DELETE /api/tasks/<id>/` - удаление задачи.

## Вывод

Все три приложения удобно реализовать через Django REST Framework, потому что их функционал строится вокруг ресурсов: пользователей, книг, ресторанов, заказов, проектов и задач. Для каждого ресурса можно создать сериализаторы, viewsets и маршруты API.
